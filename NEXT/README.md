# Drifter Loop — NEXT / незалежне ядро

**Мета:** гра-конструктор із правил, а не послідовний сценарій. Події описуються як **дані**; кожна перевіряє умови, має пріоритет, вибори та ефекти. Це самостійна реалізація ідеї storylets, без запозичення коду Hades.

## Уже є в мінімальному прототипі
- `engine.mjs`: універсальний інтерпретатор `all / any / not`, `flag / eq / ne / gte / lt`; пріоритети; одноразові події; виконання виборів; журнал; валідація.
- `events.mjs`: п'ять декларативних подій, які утворюють ланцюжок (місія → пейджер/поранення → лікування → розмова).
- `ui.mjs` + `index.html`: чорний мобільний екран зі станом світу, доступними й заблокованими подіями та причинами блокування.
- `localStorage`: окремі кнопки зберегти/завантажити, а також автозбереження після зміни стану.
- `tests.mjs`: тести логіки, ланцюжка, пріоритетів, відмови в недоступній події та round-trip збереження.

## Запуск
Потрібен HTTP-сервер, бо сторінка використовує ES-модулі:
```
cd NEXT
python -m http.server 8000
```
Відкрити `http://localhost:8000` у браузері. Для тестування з іншого пристрою потрібне доступне йому розміщення або сервер у локальній мережі.

Тести (Node 20+): `node --test tests.mjs`.

## Умови та ефекти
```js
{
  id: "treat_arthur",
  title: "Летті лікує Артура",
  priority: 80,
  once: true,
  when: { all: [
    { op: "flag", key: "arthur_injured", value: true },
    { op: "eq", path: "location", value: "medbay" }
  ] },
  choices: [{
    id: "help",
    label: "Допомогти",
    effects: [
      { op: "set_flag", key: "arthur_treated", value: true },
      { op: "set_flag", key: "arthur_injured", value: false },
      { op: "inc", path: "relationships.lettie", by: 5 }
    ]
  }]
}
```

Усе обчислюється одним ядром, без окремого коду на кожен діалог. Додавання події = додавання об'єкта в каталог.

## Залізні правила розширення
1. Стан гри — одне джерело правди. UI не створює прихованих геймплейних прапорців.
2. Будь-яка дія, що змінює світ, проходить через ядро або явно тестований системний перехід.
3. Жодного `eval` та коду всередині описів подій.
4. Збереження й завантаження тестуємо для кожної нової механіки.
5. Не переносимо весь архів назад. Переносимо лише вибраний елемент із окремим тестом.
6. Тут **ще не повна гра й не APK**: це перша перевірювана вертикальна основа.
